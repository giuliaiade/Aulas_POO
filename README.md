# 📚 Programação Orientada por Objetos (POO)

Repositório dedicado à unidade curricular de **Programação Orientada por Objetos**, onde serão reunidos os apontamentos das aulas, exemplos práticos, exercícios e outros materiais de estudo desenvolvidos ao longo do semestre.

O objetivo é consolidar os conhecimentos de programação orientada por objetos utilizando **C++**, desde os conceitos fundamentais até à modelação de software e à aplicação de padrões de desenho.

## 🎯 Objetivos

- Compreender os princípios fundamentais da programação orientada por objetos.
- Desenvolver aplicações utilizando C++.
- Aplicar mecanismos de abstração e reutilização de código.
- Modelar aplicações através de diagramas UML.
- Produzir documentação técnica.
- Compreender e implementar padrões de desenho (*Design Patterns*).

## 📖 Conteúdos programáticos

### 1. Conceitos de Programação Orientada por Objetos

- [ ] Classes e objetos
- [ ] Atributos, tipos de dados e construtores
- [ ] Variáveis e controlo de fluxo

- [ ] Métodos e argumentos
- [ ] Associações entre classes
- [ ] Herança e polimorfismo
- [ ] Classes abstratas
- [ ] Enumerações (`enum`)
- [ ] Tipos genéricos e templates

### 2. Modelação e documentação

- [ ] Diagramas UML
- [ ] Regras e ferramentas para criação de documentação

### 3. Introdução aos padrões de desenho (*Design Patterns*)

- [ ] Model-View-Controller (MVC)
- [ ] Singleton
- [ ] Composite
- [ ] Adapter
- [ ] Factory Method
